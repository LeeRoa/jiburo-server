# 화면 인벤토리 (Figma)

> [JIBURO_Web_Mobile](https://www.figma.com/design/Nz6hDq1LnXEUhu96HoEibY/JIBURO_Web_Mobile?node-id=5-16) — `Android_Mobile` 캔버스 기준

## 화면 구조

### SECTION `main` — 홈 / 게시글 / 제보 / 온보딩

- `login` — 소셜 로그인(카카오/네이버/구글), "서비스 시작하기"
- `main` — 홈(지도 + 카드리스트), 지도 스켈레톤 로딩
- `main_scroll` — 스크롤 시 등록 FAB 노출
- `main_refresh` — 새로고침, 스낵바
- `main_typing` / `main_search` — 검색 타이핑 / 검색 결과
- `alarm` — 알림 목록
- `map` — 지도 단독 화면(내 위치 버튼)
- `map_avatar` — 지도 핀(아바타) 클릭 시 게시글 미리보기 바텀시트
- `pet_profile` (다수 변형) — 게시글 상세: 저장 전/후, 찾기 완료, 사진 페이지네이션, 실종위치 지도, 댓글/피드백("이 근처를 탐색했어요"), 액션 버튼(주변탐색 +50xp / 채팅하기 / 공유 / 저장)
- `information 1/2/3` — 실종정보 등록 마법사 4단계(stepper: 실종위치 → 실종정보 → 사진등록 → 추가내용)
- `rander` — 로고 스플래시 페이지

### SECTION `message` — 채팅

- `message_list` — 전체/안읽음 필터
- `chat_normal`, `chat_menu`, `chat_alarm`(알림 끄기/음소거), `chat_quit_chat`(채팅방 나가기 확인 모달), `chat_typing`
- `message` — 빈 대화기록

### SECTION `like` — 좋아요/저장(찜)

- `like_empty`
- `like_main` — 찾는 중/찾기 완료 필터, 체크박스 다중선택
- `like_delete` — 삭제 모드/삭제 확인 모달

### 탐색(주변탐색) — 별도 bottom nav (길찾기 / 주변탐색 / 촬영)

- 탐색 모드(반경 표시, "탐색가능 지역으로 이동해주세요")
- 촬영 기록(사진 그리드 + 추가정보 입력)
- 탐색 완료("50xp를 드릴게요")

### SECTION `my_page` — 마이페이지

- `mypage_main` — 프로필 / 레벨·XP / 내 게시물 / 내 활동 / 계정관리 / 약관 / 회원탈퇴
- 내 게시물 전체보기, 프로필 수정, 내 활동 전체보기

### SECTION `optional`

- `loading`, `404_error`, `empty`

## 기능 / 필드 인벤토리

- **인증**: 카카오/네이버/구글 소셜 로그인 버튼
- **홈/검색**: 지역명/이름 검색창, 정렬 필터(거리순/최신순), 카드 리스트(사진/이름/위치/거리/사례금/등록시각/찜 아이콘)
- **게시글 상세**: 이름/동물종/특징(성별·나이·몸무게)/사례금, 실종 위치 지도, 상태(찾는 중/찾기 완료), 주변탐색(+50xp)/채팅하기/공유/저장 버튼, 코멘트(피드백) 목록
- **게시글 등록 마법사**: 이름*, 실종동물*(강아지/고양이/이구아나/토끼 등), 종 구분*, 성별*, 나이, 몸무게(kg), 사례금, 위치 핀 선택, 장소 검색(거리 표시), 사진 4종(정면/옆모습/특징/착용품) 업로드 가이드, 제목, 추가내용(개인정보 미포함 경고), "게시하기"
- **채팅**: 전체/안읽음 필터, 읽음 수 뱃지, 이미지 전송, 이모티콘, 메뉴(알림 끄기=음소거, 채팅방 나가기=대화삭제)
- **좋아요/저장(찜)**: 찾는 중/찾기 완료 필터, 체크박스 다중선택 삭제, 개별 항목 삭제 확인 모달
- **탐색(주변탐색)**: 거리 반경 아바타, 위치 알람 끄기, 촬영 기록(사진), 탐색 시작/종료, 완료 시 XP 보상
- **마이페이지**: 닉네임/로그인수단 표시, 프로필 수정(아바타/닉네임), 레벨·XP 게이지, 내 게시물(상태 필터), 내 활동(지도 썸네일+날짜), 계정관리(알림·위치 설정/공지사항/1:1 문의하기/로그아웃), 서비스 이용약관/개인정보처리방침/위치기반서비스 이용약관, 회원탈퇴
- **공통**: 스낵바 토스트, 삭제/나가기 확인 모달, 404/로딩/빈 화면

## 불확실 항목 (텍스트만으로 확정 어려움)

- "무는지 여부" 필드는 디자이너 주석(등록 폼 설계 메모)에는 언급되나 실제 등록 폼 화면 캡처에는 직접 노출되지 않음 → 코드 확인 결과 이미 `AnimalDetailDto.isBiting`으로 구현됨 (→ [02-backend-gap-analysis.md](./02-backend-gap-analysis.md))
- XP/레벨 시스템의 구체적 임계값·행동별 보상 규칙 전체 목록은 디자인에 일부만 노출되어 전체 규칙은 추정 불가
- "주변탐색"이 실제 GPS 워킹 트래킹인지 단순 지도 인터랙션 연출인지는 텍스트만으로 완전히 확정하기 어려움 (코드 확인 결과 `FinderController`의 `route` 기록 API가 GPS 좌표 배열을 받는 것으로 보아 실제 트래킹으로 판단됨)
